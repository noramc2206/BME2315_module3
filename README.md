This project investigates whether Cavalitide, a proposed oral GLP-1 receptor agonist, could be developed as a treatment for obesity. Using experimental receptor activation data from cavalitide_data.csv, we first estimated Cavalitide's receptor binding affinity and compared it to semaglutide. We then created pharmacokinetic and pharmacodynamic models in Python to simulate drug concentration and GLP1 receptor activation over time. The overall goal was to evaluate dosing strategies and assess Cavalitide's potential as a competitor to existing GLP-1 therapies such as Ozempic and Wegovy.
